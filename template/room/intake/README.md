# Intake: ROOM NAME

Everything known about the room as it is today. Originals stay here untouched; `IMG_*.jpg`
copies of iPhone HEIC photos come from `lib/tools/heic2jpg.sh`.

## Photos

Shoot with the phone's 0.5× lens, standing in each corner at about chest height.

- [ ] **Each corner:** from each corner, aim at the opposite corner, so every wall shows in at
      least two photos.
- [ ] **Each wall:** straight on, from as far back as you can stand.
- [ ] **Ceiling:** lights, vents, fans, soffits, beams.
- [ ] **Floor:** close enough to see the material, plus any vents.
- [ ] **Every door and window:** with its trim.
- [ ] **Outlets, switches and vents:** with enough of the wall around each one to place it.
- [ ] **The doorway from the next room:** looking in, and looking out.
- [ ] **Anything staying:** toilet, cabinets, furniture, radiators, and so on.
- [ ] **A tape measure in a few shots:** stretched along a wall or across a window. This gives
      the scale for everything else in the photo.

## Measurements

Inches. Leave a line blank if you can't measure it, and it gets estimated from the photos.

| What | Measurement | How (tape / plan / photo / guess) |
|---|---|---|
| Ceiling height | | |
| Room length, wall to wall (each direction) | | |
| Each door: width, height, distance from the nearest corner to the trim | | |
| Each window: width, height, floor to sill, distance from the nearest corner | | |
| Anything odd: soffits, angled walls, steps, bump-outs | | |
| Big fixtures that stay: width and position | | |

**No floor plan?** That's fine. Get the ceiling height, the room's length and width, and one
door or window. Everything else gets estimated from the photos, using the tape measure in the
shots and standard sizes for scale: doors are usually 80" tall, outlet covers about 4.5",
counters 34–36" high, plus floor tiles if you know their size. A rough sketch of the room's
shape on paper (a photo of it is fine), with a label on each wall ("window", "door to hall"),
helps a lot.

**Room-scanning app:** an iPhone Pro (with the depth scanner) and an app such as Polycam or
magicplan can scan the room in a minute or two and export a plan with dimensions. Treat it like
a listing plan: a good start, checked with a couple of tape measurements.
